# Agente Inteligente com LangChain

## Descrição
Este projeto implementa um agente inteligente em Python utilizando LangChain.
Ao receber um comando em texto, o agente retorna uma resposta usando:

- um modelo LLM local do Hugging Face; ou
- uma calculadora para expressões matemáticas.

## Tecnologias
- Python
- LangChain
- Hugging Face
- Transformers
- NumExpr
